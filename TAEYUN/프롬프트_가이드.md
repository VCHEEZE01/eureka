```text
너는 지금부터 "유레카(Eureka)" 프로젝트에 합류한 팀원이다.
팀명은 목욕중이고, AI 에이전트 기반 웹 서비스를 만들고 있다.

────────────────────────────────
[1] 저장소를 받아와라  ※ 이미 받았으면 건너뛸 것

모든 자료는 TAEYUN/ 폴더에 있다.
이미 이 폴더 안에 있다면 이 단계는 생략하고 [2]로 가라.

────────────────────────────────
[2] 아래 순서 그대로 읽어라
────────────────────────────────

순서가 중요하다. 아무 순서로 읽으면 맥락이 꼬인다.

■ 무엇을 만드는가
  1. TAEYUN/Eureka_PRD_v2.md
     기능 정의서. 5절(기능 목록) · 6절(기능 상세) · 10절(미정 항목)을 특히 자세히.
  2. TAEYUN/flow_diagram_abstract.png
     화면이 어떻게 이어지는지 한 장. 색깔은 개인화 포인트 3개, 주황 점선은 이탈 지점.

■ 어떻게 생겼는가
  3. TAEYUN/에이전트_흐름도.html

  4. TAEYUN/유레카_임시_DESIGN.md

■ 어떻게 만들 것인가
  5. TAEYUN/아키텍처_설계.md
     시스템 설계 전체. 폴더 구조·데이터 모델·개발 단계·테스트 전략.

  8. TAEYUN/prototype/README.md

  9. TAEYUN/prototype/src/

직접 눈으로 확인하고 싶으면 이 두 파일을 브라우저로 열어봐도 된다.
설치나 서버 없이 그냥 열린다.

────────────────────────────────
[3] 다 읽고 나서 아래를 정리해라

2. 에이전트가 몇 개이고 각각 무슨 일을 하는가
3. "배치"와 "실시간"이 왜 나뉘어 있는가. 안 나누면 무슨 일이 생기는가
4. 지금 어디까지 만들어져 있고, 무엇이 아직 없는가
5. 아직 안 정해진 것들 중, 지금 정하지 않으면 개발이 막히는 것은 무엇인가
6. 네가 보기에 이 설계에서 위험하거나 빠져 있는 지점은 무엇인가

────────────────────────────────
[4] 읽을 때 반드시 확인할 제약 7가지

이 프로젝트를 일반적인 AI 서비스와 다르게 만드는 조건들이다.
설계 문서가 이걸 어떻게 지키고 있는지 확인하면서 읽어라.

  1. 실행 축이 두 개다 — 미리 돌려두는 배치 / 사용자가 기다리는 실시간
  2. 근거 없는 수치를 만들면 안 된다 — 숫자는 DB 집계에서만 나온다
  3. 실제 수집 근거와 AI가 쓴 설명은 화면에서 구분되어야 한다
  4. 단일 검증점수를 제공하지 않는다 — 근거 건수와 출처 수로 대신한다
  5. 같은 입력이면 항상 같은 결과가 나와야 한다
  6. 실시간 생성 3곳에서 진행 상태를 단계별로 보여줘야 한다
  7. 서버 없이 열리는 단일 HTML 공유본을 계속 유지해야 한다

────────────────────────────────
[5] 그 다음
────────────────────────────────

정리를 마치면 멈추고, 내가 어떤 역할을 맡을지 물어봐라.
내 답에 따라 다음에 할 일을 제안해라. 역할은 넷 중 하나다.

  - 기획         : 미정 항목 정리, 결정 우선순위
  - 백엔드       : 스키마와 API 계약부터
  - 프론트엔드   : 기존 화면 13개 이전
  - 데이터 수집  : 네이버·카카오 API로 실제 수집

중요: 지금 단계에서는 코드를 작성하지 마라.
읽고, 파악하고, 정리하고, 물어봐라. 구현은 내가 승인한 뒤에 한다.
```

## 참고 — 알아두면 좋은 것

**프로토타입 소스를 직접 돌리려면**

```bash
cd TAEYUN/prototype
npm install          # 처음 한 번 (435MB, 깃에는 없음)
npm run dev          # http://localhost:3000
npm run build:single # 공유용 HTML 다시 만들기
```

**현재 상태 요약**

- 표시되는 문제·아이디어·수치는 **전부 가상 데이터**입니다. 실제 수집 결과가 아닙니다
- 백엔드는 **코드 0줄**. 설계 문서만 있습니다
- 프로토타입이 **두 벌** 있습니다 (`박민규` 브랜치 / `taeyun` 브랜치) — 정리가 필요합니다
- `eureka/docs/DATA_SOURCES.md`(박민규 브랜치)는 수집 파이프라인 만들 때 꼭 필요합니다
