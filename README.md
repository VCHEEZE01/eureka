## Overview

유레카는 만들 수 있는 능력은 있지만 "무엇을 만들지" 정하지 못한 메이커를 위한 서비스입니다.
커뮤니티, 리뷰, SNS 등 실제 사용자의 반응 데이터를 바탕으로 세상에 존재하는 문제를 발견하고,
문제의 근거와 검증 점수를 함께 보여준 뒤 실행 가능한 서비스 아이디어로 연결합니다.

팀명은 **목욕중**입니다.

## Core Value

- 실제 데이터에 기반한 문제 발견
- 문제별 근거, 언급량, 추세, 출처 제공
- 검증된 문제에서 바로 이어지는 아이디어 추천
- 여러 문제와 사용자의 조건을 조합한 맞춤 아이디어 생성
- 마음에 드는 문제와 아이디어를 저장하고 다시 확인하는 마이페이지

## Target User

주요 사용자는 방향을 찾는 초기 메이커입니다.

- AI 코딩 도구로 빠르게 MVP를 만들 수 있지만 아이템 선정이 어려운 사람
- 사이드 프로젝트를 여러 번 시도했지만 문제 검증에서 막힌 사람
- 1인 창업자, 프리랜서, 예비 창업자처럼 다음 아이디어가 필요한 사람

## Main Flow

1. 랜딩 페이지에서 서비스 가치와 작동 방식을 이해합니다.
2. 문제 리스트에서 검증 점수가 높은 문제를 탐색합니다.
3. 문제 상세에서 근거 데이터, 언급량, 추세, 출처 분포를 확인합니다.
4. 해당 문제에서 발견된 아이디어 목록을 확인합니다.
5. 필요하면 여러 문제와 개인 조건을 조합해 초개인화 아이디어를 요청합니다.
6. 맞춤 아이디어 결과와 상세 근거를 확인합니다.
7. 즐겨찾기한 문제와 아이디어를 마이페이지에서 다시 봅니다.

## MVP Features

- 랜딩 페이지
- 문제 리스트
- 문제 상세
- 문제 기반 아이디어 목록
- 초개인화 아이디어 요청 폼
- 초개인화 아이디어 결과 목록
- 아이디어 상세
- 마이페이지
- 로그인 및 즐겨찾기
